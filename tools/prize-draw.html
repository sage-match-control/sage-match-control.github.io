No Rigging Zone

The list is locked before anything is drawn. Once the first spin happens, nobody can quietly add or remove a name. The page shows a fingerprint of the locked list: change one letter and it changes. If the list has to change after that, the draw closes and a new part starts, and both parts stay on record.

A random code decides every spin. When the list is locked, the page makes a random draw code. For each spin, every name still in the draw gets a code made from the draw code, the spin number and the name (a SHA-256 hash), and the smallest wins. Nobody can steer it, not even the person running the draw. The spinning on screen only shows a result that was already fixed. The prizes never enter it, so changing their order can't favour anyone.

Anyone can check it. With the list, the draw code and the rule, Check this draw works every spin out again and shows whether each recorded winner is the one the code gives.
